# Tableau Dashboard

This folder contains the packaged Tableau workbook and dashboard preview for the
Mansfield Residential Listing Analysis project.

## Preview

![Mansfield Residential Listing Analysis dashboard](mansfield-listing-dashboard.png)

## Packaged Workbook

[Download the Tableau workbook](Mansfield%20Residential%20Listing%20Analysis.twbx)

The workbook includes a Tableau extract and can be opened without reconnecting
to the original local Excel path.

## Dashboard Components

- Four median-focused KPI cards
- Listing price versus property size scatterplot
- Median listing price by bedroom and bathroom group
- Median price per square foot by listing type
- Price-per-square-foot distribution
- Geographic distribution of archived listings
- Interactive filters for price, size, beds, baths, and listing type

## Analytical Guardrail

Listing-type comparisons are descriptive. Groups are unequal in size, and
property condition, repair costs, and neighborhood characteristics are
unavailable.

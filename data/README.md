# Data

`Real Estate Listings.xlsx` contains 336 archived residential listings from
Mansfield, Texas.

The file was previously obtained from Kaggle, but the original dataset URL and
collection date are no longer available. The repository preserves the source
file used in the analysis without claiming that it represents the current
market.

See [`data-dictionary.md`](data-dictionary.md) for field definitions and data
quality notes.
